# Letter from a storyteller

A story mod's letter sent from code (`wwhd_mail_send`): it waits in the Rito postbox of the loaded
save file and arrives once per file. The text is original. A letter that needs no condition of your
own can also be declared in the manifest (`letters`), with no code, as the [Old map](../story-chart/)
example does. Needs port 0.3.0 and the Story Notebook package (the port's story system).
