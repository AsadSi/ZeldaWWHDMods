# Letter from a storyteller

A story mod's letter (`wwhd_mail_send`): it waits in the Rito postbox of the loaded save file and
arrives once per file. The text is original.

This example shows the code way, for a letter that depends on the mod's own conditions. A letter can
also be declared in the manifest with no code, as the [Old map](../story-chart/) example does. Needs
the Story Notebook package (the port's story system).
